## Getting Started

This project runs inside a pre-configured dev container with several AI coding agents
(Claude Code, Codex, OpenCode, Pi, Grok CLI) and local LLM services already set up.

- Open the project in VS Code and **Reopen in Container** when prompted.
- Start a coding agent from the terminal (`claude`, `codex`, `opencode`, `pi`, or `grok`) and run
  its `/init` command to scaffold project-specific agent instructions for your codebase.
- For the container's services (the unified LiteLLM endpoint, Open WebUI chat, web search,
  and the AI sandbox terminal) and maintenance tasks, see
  [`.devcontainer/README.md`](.devcontainer/README.md).
