# Browser Chat Stack

Installs the browser-chat stack (LiteLLM proxy, Open WebUI, Open Terminal, SearXNG, supervisord) in one pinned bundle via uv.

```json
{
  "features": {
    "ghcr.io/cmu-sei/devcontainer-features/chat:1": {}
  }
}
```


See the [collection README](../../README.md) for the supported base, profiles, persistence, and release process.
