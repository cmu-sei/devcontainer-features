# tmux Configuration

Installs the dev container's ~/.tmux.conf (256-color/UTF-8, CSI u extended keys, scrollback, mouse, zsh as the default shell).

```json
{
  "features": {
    "ghcr.io/cmu-sei/devcontainer-features/tmux:1": {}
  }
}
```


See the [collection README](../../README.md) for the supported base, profiles, persistence, and release process.
