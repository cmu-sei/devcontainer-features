# Pure Prompt (Zsh)

Installs the Pure Zsh prompt in place of the oh-my-zsh theme, and enables the shell prompt's git dirty indicator.

```json
{
  "features": {
    "ghcr.io/cmu-sei/devcontainer-features/pure-prompt:1": {}
  }
}
```


See the [collection README](../../README.md) for the supported base, profiles, persistence, and release process.
