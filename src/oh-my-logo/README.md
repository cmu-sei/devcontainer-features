# Oh My Logo

Installs the oh-my-logo npm package globally.

```json
{
  "features": {
    "ghcr.io/cmu-sei/devcontainer-features/oh-my-logo:1": {}
  }
}
```

| Option | Default | Meaning |
| --- | --- | --- |
| `version` | `0.5.0` | Exact upstream tool version installed at image build time. |

See the [collection README](../../README.md) for the supported base, profiles, persistence, and release process.
